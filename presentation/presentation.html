Part 1

IDE Comparison

Cursor vs Claude Code

Cursor

VS Code fork with AI deeply integrated

  • Tab Completion — Autocomplete on steroids, predicts multi-line changes
  • Cmd+K — Inline editing with natural language
  • Composer — Multi-file changes in one go
  • Chat Panel — Codebase-aware with @-mentions

Cursor — What’s New

From the current docs: ecosystem around agents, then review & diagnosis

  • Plugins ship rules, skills, agents, commands, MCP servers & hooks together.
  • Bugbot reviews GitHub PRs; Debug mode gathers runtime evidence before fixing.

Claude Code

Terminal-based agentic coding assistant

  • Editor Agnostic — Works alongside any editor you prefer
  • Autonomous — File editing + command execution
  • Deep Exploration — Understands entire codebase context
  • Git Integration — Commits, PRs, branches built-in

Claude Code — What’s New

From the current docs: terminal agent → editor & safety → platform → integrations

  • VS Code / Cursor extension — inline diffs, @-mentions, plan review, checkpoint rewind.
  • MCP connects tools; hooks automate around tool use; sandbox bounds bash.

When to Use Which?

Cursor Claude Code
Quick edits, autocomplete Large refactors, greenfield projects
Visual diff review preferred Comfortable with terminal
Tight editor integration Complex multi-step tasks
Smaller, focused changes Full-stack scaffolding

Both support SKILL.md for custom workflows. They work great together — Claude Code for big changes, Cursor for refinement.

Part 2

Guided
Assignment

45 minutes hands-on

Assignment Options

  • A: Extend the Dashboard — Existing app • Add live API widgets to a partial dashboard
  • B: Debug the Todo App — Existing app • Find & fix 3 intentional bugs
  • C: MCP Power Tools — Claude Code • Configure & use MCP servers
  • D: UI Redesign via Skill — Claude Code • Write & iterate a /redesign slash command

Option A — Extend the Dashboard

cd assignment-a-dashboard-app && npm run dev
  • 3 live widgets already built — use them as patterns
  • Implement Weather card — Open-Meteo API (no key needed)
  • Implement Crypto Markets card — CoinGecko API (BTC, ETH, SOL)
  • Implement News Headlines card — Hacker News Algolia API
  • Optional: Requests Table or chart with recharts
  • All server components, all public APIs, no auth required

Option B — Debug the Todo App

cd assignment-b-todo-app && npm run dev
  • The app has 3 intentional bugs hidden in src/app/page.tsx
  • Use AI to explore the code, describe symptoms, and locate root causes
  • Fix each bug with AI assistance — verify behaviour after each fix
  • Bonus: add localStorage persistence so todos survive refresh
  • Bonus: add a “Edit” feature to rename a todo in-place

Option C — MCP Power Tools

claude mcp add context7 npx -- -y @upstash/context7-mcp
  • Configure 2–3 MCP servers in Claude Code
  • context7 — ask Claude for up-to-date Next.js & Tailwind docs
  • GitHub MCP — browse issues, open PRs, summarise a repo
  • Compare answers with vs without MCP context
  • Use the live context to add a new widget to the dashboard app
  • Bonus: configure MCP in Cursor via .cursor/mcp.json and compare

Option D — UI Redesign with a Skill

~/.claude/commands/redesign.md
  • Write a /redesign slash command that instructs Claude how to critique and improve any component's UI/UX
  • Run it on the todo app — dark theme, spacing, animations, accessibility
  • Iterate: refine the skill prompt, run again, compare results
  • Add a CLAUDE.md with your design tokens and conventions
  • Bonus: add a /component skill that scaffolds new styled components
  • Bonus: configure an equivalent .cursor/rules file for Cursor

Part 3

Best Practices

Tips for effective AI-assisted coding

Context Management

Bad: “Fix the login bug”

Good: “In src/auth/validate.ts, JWT validation fails when tokens contain special characters. Error on line 45.”

  • Reference files explicitly — use @-mentions or paths
  • Chunk large tasks — smaller, verifiable steps
  • Fresh context — new session for unrelated tasks

Prompting Techniques

1. Goal first, then constraints

"Build a user registration form.
Constraints: react-hook-form, zod validation,
no external UI libraries."

2. Provide examples

"Format output like: { id: string, name: string }"

3. Ask for explanation first

4. Iterate, don’t restart

Project Configuration

.cursorrules

You are working on Next.js 14:
- App Router (not Pages)
- TypeScript strict mode
- Tailwind CSS

Rules:
- No 'use client' unless needed
- Use named exports
- Prefer Server Actions

CLAUDE.md

# Project: Dashboard

## Stack
- Next.js 14, TypeScript
- Prisma + PostgreSQL

## Don't
- Don't use `any` type
- Don't install deps without asking

MCP — Model Context Protocol

Connect AI to external tools and data

  • Database Access — Query Postgres directly
  • Documentation — Fetch from Notion, Confluence
  • Design Tools — Pull from Figma
  • Custom Tools — Internal APIs, services

Keep it simple: most projects don’t need MCP. Start without it.
