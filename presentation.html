IDE Comparison

Cursor vs Claude Code

Cursor

Cmd+K

Multi-file changes in one go

Cursor — What’s New

Late 2025 – Early 2026

  • Subagents — parallel specialized agents for discrete subtasks
  • Agent Skills — SKILL.md files for dynamic context & workflows
  • Image generation — create UI mockups & assets from the agent
  • Plan & Ask modes — now in CLI, with cloud handoff
  • Cursor Blame (Enterprise) — AI attribution for git
  • Clarification questions from agents mid-conversation

Claude Code

Terminal-based agentic coding assistant

Editor Agnostic

Works alongside any editor you prefer

Autonomous

File editing + command execution

Deep Exploration

Understands entire codebase context

Git Integration

Commits, PRs, branches built-in

Claude Code — What’s New

GA May 2025 • Terminal, VS Code, Web, Desktop, JetBrains

  • Agent teams — multi-agent collaboration (experimental)
  • Skills & slash commands — SKILL.md, custom workflows
  • Hooks system — automation, guardrails, pre/post actions
  • MCP — Model Context Protocol for external tools
  • Memory & recall — Claude records and recalls as it works
  • Session forking, --from-pr, background tasks, Opus 4.6

When to Use Which?

Cursor Claude Code
Quick edits, autocomplete Large refactors, greenfield projects
Visual diff review preferred Comfortable with terminal
Tight editor integration Complex multi-step tasks
Smaller, focused changes Full-stack scaffolding

Both support SKILL.md for custom workflows. They work great together — Claude Code for big changes, Cursor for refinement.

Option A — Extend the Dashboard

cd workshop-dashboard-app && npm run dev
  • 3 live widgets already built — use them as patterns
  • Implement Weather card — Open-Meteo API (no key needed)
  • Implement Crypto Markets card — CoinGecko API (BTC, ETH, SOL)
  • Implement News Headlines card — Hacker News Algolia API
  • Optional: Requests Table or chart with recharts
  • All server components, all public APIs, no auth required

Option B — Debug the Todo App

cd workshop-todo-app && npm run dev
  • The app has 3 intentional bugs hidden in src/app/page.tsx
  • Use AI to explore the code, describe symptoms, and locate root causes
  • Fix each bug with AI assistance — verify behaviour after each fix
  • Bonus: add localStorage persistence so todos survive refresh
  • Bonus: add a “Edit” feature to rename a todo in-place

Option C — API Search App

npx create-next-app@latest
  • Search input that calls a public API via a Server Action
  • Pick any API: OMDB (movies), OpenWeatherMap, CoinGecko, or Hacker News
  • Display results in cards or a list
  • Handle loading states and errors gracefully
  • Store recent searches in localStorage
  • Fully responsive, styled with Tailwind CSS

Option D — AI Chatbot

npx create-next-app@latest
  • Chat UI with message bubbles (user & assistant)
  • Next.js Route Handler calling the Anthropic Claude API
  • Stream the response so text appears token-by-token
  • Keep full conversation history in state
  • Bonus: system prompt input to customise the assistant persona
  • Bonus: copy-to-clipboard or clear-conversation button

Part 3

Best Practices

Tips for effective AI-assisted coding

Context Management

Bad: “Fix the login bug”

Good: “In src/auth/validate.ts, JWT validation fails when tokens contain special characters. Error on line 45.”

  • Reference files explicitly — use @-mentions or paths
  • Chunk large tasks — smaller, verifiable steps
  • Fresh context — new session for unrelated tasks

Prompting Techniques

1. Goal first, then constraints

"Build a user registration form.
Constraints: react-hook-form, zod validation,
no external UI libraries."

2. Provide examples

"Format output like: { id: string, name: string }"

3. Ask for explanation first

4. Iterate, don’t restart

Project Configuration

.cursorrules

You are working on Next.js 14:
- App Router (not Pages)
- TypeScript strict mode
- Tailwind CSS

Rules:
- No 'use client' unless needed
- Use named exports
- Prefer Server Actions
